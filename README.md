# 通勤電車VR

**体験できるURL：https://katomi95.github.io/tsuukin-densha-vr/**（Meta Quest 3 のブラウザで開いてください。PCではプレビューモードで見られます）

**帰ってきたのに、気が休まらない。**

Meta Quest 3 のパススルーMRで、帰宅した自分の部屋が満員の通勤電車になる作品です。
ゲームではありません。スコアも、クリアも、敵も、脱出もありません。
終点に着いて乗客がいなくなっても、少しの静寂のあと「まもなく、始発駅です」。最後まで救済しません。

ヘッドセットを外す自由だけは残してあります。

## 動作環境

- Meta Quest 3 の標準ブラウザ（Quest Browser）
- WebXR `immersive-ar`（パススルー）＋ Three.js r165（`vendor/` に同梱。CDN に依存しない）
- 静的ファイルだけで動きます（GitHub Pages 等）。サーバー処理なし
- コントローラーなしでも体験できます（操作は「おわる」のみ。ハンドトラッキングのピンチでも出せる）
- 使う WebXR の機能は `immersive-ar` と `local-floor`（任意）だけ。平面検出・深度・アンカー・DOM Overlay・ハンドトラッキング API には依存しません

## Quest 3 での起動手順

1. このフォルダを HTTPS の静的ホスティング（GitHub Pages など）に置く。WebXR は `https://`（または `localhost`）でしか動きません。
2. Quest 3 の **ブラウザ** でそのURLを開く。
3. 混み具合・部屋の広さ・音量・アナウンスの読み上げを選び、注意書きを読んで **「ただいま」** を押す。パススルーの許可を求められたら許可する。
4. そのとき向いていた方が、車内の「前」になります（電光掲示が前と後ろに1台ずつ出ます）。あとは何もしなくてかまいません。

### おわるとき

- トリガー（またはピンチ）を引くと、正面に「おわる」が出ます。それを指してもう一度。何もしなければ7秒で消えます。
- Meta ボタン → 終了（Quest のシステム操作はいつでも使えます）。
- ヘッドセットを外す。

### PC でのプレビュー

タイトルの「PCプレビュー」で、仮の部屋に乗客を重ねて見られます。ドラッグで見回し、WASD／矢印キーで歩けます。

確認用の URL パラメータ：

| パラメータ | 内容 |
| --- | --- |
| `?t=120` | 始まってすぐ、その秒数まで早送りする（音と声は止めたまま進める） |
| `?events=seat,gaze,delay` | 3回の出来事を指定する（`brake` `gaze` `manner` `seat` `delay`）。1・2回目は走行中、3回目は停車中に起きる |
| `?seed=123` | 乗客の顔ぶれと出来事の抽選を固定する |
| `?sit=1` | プレビューの目の高さを座った人（1.15m）にする |

ローカルで動かすときは、`.js` を `text/javascript` で返すサーバーで配信してください（例：`python -m http.server`）。
開発中の確認は `window.__densha`（`startPreview()` / `director.fastForward(秒)` / `frame(dt)` / `lookAtPoint(x,y,z)`）から行えます。

## 流れ（1周 約3分20秒、2周目からは約3分15秒）

| 時刻 | できごと |
| --- | --- |
| 0:01 | 「通勤電車VR」「おかえりなさい。今日も一日お疲れさまでした。」 |
| 0:07 | 電光掲示が現れ、「まもなく、満員、満員です。」 |
| 0:10 | 空中に吊り革が下りてくる。**第1段階**：乗客が5人ほど、少し離れたところに静かに現れる |
| 0:18 | 発車。走行音・レールの継ぎ目の音 |
| 0:42 | 停車。「ただいま　自宅」。ドアチャイム。**第2段階**：乗客が歩いて乗ってくる。中吊り広告、吊り革が増える |
| 0:55 | 横に立った人のスマホ画面（乗換案内：自宅→自宅、到着時刻：未定）が、顔の近くまでゆっくり上がってくる |
| 1:04 | 不条理イベント 1（走行中） |
| 1:26 | 停車。**第3段階**：超満員。目の前に後頭部。顔のすぐ横に吊り革。走行音が大きくなる。イヤホンの音漏れ |
| 1:39 | 誰かのリュックが、ゆっくり視界に入ってくる |
| 1:44 | 不条理イベント 2（走行中） |
| 1:54 | 駅でもないところで停車。「ただいま、前の電車がつかえております」「お急ぎのところ、申し訳ございません」「なお、運転再開の見込みは、立っておりません」 |
| 2:24 | 不条理イベント 3（停車中） |
| 2:48 | 「まもなく、終点です。」乗客が一人ずつ消え、走行音が小さくなり、吊り革も広告も消える |
| 3:10 | 静かな自室。「お疲れさまでした」。数秒間、完全な静寂 |
| 3:22 | 「まもなく、始発駅です。」→ 乗客が再び現れはじめる（ループ） |

時刻は `js/director.js` の `CONFIG.T` でまとめて調整できます。

### 不条理イベント（毎周ランダムに3つ）

| 名前 | 内容 |
| --- | --- |
| 急ブレーキ（brake） | 「急停車します。ご注意ください。」→ 乗客だけが一斉に傾き、吊り革が大きく揺れる。**プレイヤーの視点と現実の部屋は一切揺らさない** |
| 謎の視線（gaze） | 斜め前の乗客がゆっくりこちらを向き、数秒間無言で見つめ、何事もなかったように戻る |
| 車内マナー（manner） | 「車内では、携帯電話をマナーモードに設定してください。」→ 直後に4〜6人の着信音が一斉に鳴る |
| 席を譲られる（seat） | 何もない空中に座っていた乗客が立ち上がり、こちらを見て、空いた場所を手で示す。そこに椅子はない（着席は促さない） |
| 終わらない遅延（delay） | 「ただいま、運転を見合わせております」→「運転再開まで、今しばらくお待ちください」→「本日はご利用いただき、誠にありがとうございます」。何も解決しない |

## 中身

- **乗客**：Three.js のプリミティブを組み合わせたローポリ人形（頂点色＋フラットシェーディング、テクスチャなし）。背丈・体格・肌・髪型（短髪／七三／薄毛／ロング／ボブ／お団子）・スーツ／私服／学ラン・ネクタイ・スカート・眼鏡・マスク・イヤホン・鞄（ビジネスバッグ／ショルダー／リュック／前抱えリュック）・姿勢（スマホ／新聞／吊り革／居眠り／手ぶら）を毎回組み合わせて作る。目は細く、口は一文字、くまが少し
- ふつうの乗客は「体」と「頭」の2メッシュだけ（ポーズは作るときに焼き込み）。席を譲る人とスマホの人だけ関節ごとに動く
- **吊り革**：握り棒から巻き尺のように伸びて下りてくる。加減速とブレーキでばねのように揺れる（インスタンス描画）
- **中吊り広告**：すべて架空（週刊 帰宅「玄関で3時間 立ち尽くす人々」、駅から徒歩0分。というか、駅。、定期券 自宅⇔自宅 6か月0円、など9種）。起動時に Canvas で描く
- **車内案内表示**：LED風の電光掲示（「次は　自宅　じたく」「この電車は　各駅停車　自宅 行きです」）。アナウンスの文字もここに流れるので、音声合成が使えない端末でも内容が分かる
- 描画は混雑の最大時でも 70 コール前後・約1.6万ポリゴン（PCヘッドレス計測）

## 音

**すべて Web Audio API による合成音です。音声ファイルは1つもありません。**
走行音（ブラウンノイズ＋風切り＋モーターのうなり。加減速で音程が動く）、レールの継ぎ目（25mごと、速さに応じた間隔の「タタン、タタン」）、空調、停車中のコンプレッサー、ブレーキのきしみ、空気の抜ける音、ドアチャイムとドアの開閉、案内放送のチャイム、衣擦れ、足音、吊り革のカタカタ、5種類の着信音、イヤホンの音漏れ。乗客の音は HRTF の立体音響でその人の位置から鳴ります。

チャイムと着信音のメロディーはこの作品のための自作です（実在の鉄道会社・端末の音を真似たものではありません）。

**車内アナウンス**は、体験する端末に入っている日本語の音声合成（Web Speech API の `speechSynthesis`）でその場で読み上げます。録音した声も、実在の鉄道会社の放送も使っていません。音声ファイルを配布しないので、公開しても音声の権利の問題は生じません。
日本語の音声合成が無い端末では声は出ず、チャイムと電光掲示の文字だけになります（タイトル画面に、その端末で読み上げられるかどうかを表示します）。

## 安全のために決めていること

- 視点の移動・回転・揺れは一切ない。ブレーキで揺れるのは乗客と吊り革と広告だけ
- 歩く必要はない。立っていても座っていても体験できる（吊り革の高さは開始時の目の高さに合わせ、1.62〜1.82m の範囲に収める）
- 乗客が頭に近づきすぎると自動で透ける（頭から約30cm以内）。乗客の移動は最大でも毎秒0.45m、顔の近くに来るものは毎秒0.07m程度
- 目の前の人・スマホ・リュックの距離は混み具合の設定で変わる（「ほどほど」なら目の前の人まで約78cm）
- 現実の部屋を覆い隠す壁・床・窓などの「車両」は描かない。部屋が見えていること自体が作品の要素
- 強い光の点滅・急な大音量はない（ブレーキ音・着信音もコンプレッサーで頭打ち）
- 席を譲られても着席は促さない。開始前の注意書きで「座らないでください」と明記
- 終了はいつでも：トリガー／ピンチの「おわる」、Meta ボタン、ヘッドセットを外す

## Quest 3 実機での確認項目（未確認）

PC のヘッドレス Chrome（SwiftShader）では、全段階・全イベント・ループ・タイトルへの戻りまでを例外なしで確認済みです。Quest 3 実機ではまだ確認していません。実機では次を確認してください。

1. 「ただいま」でパススルーが始まり、部屋が見えたままタイトルの板が正面に出る
2. 乗客が床に立っている（浮いたり沈んだりしない）。`local-floor` が使えない環境では目の高さ1.6mと仮定するので、座っていると乗客が沈んで見える
3. 吊り革の輪が、立っていても座っていても目より少し上にある
4. 乗客の足元の向こうに現実の床・家具が見えていて、「部屋の中に電車が来た」と感じられる
5. 走行音・レールの継ぎ目の音・ドアチャイムが鳴る。乗客の衣擦れや着信音が、その人の方向から聞こえる
6. 車内アナウンスが日本語で読み上げられる（Quest Browser の `speechSynthesis` に日本語音声があるか）。無い場合は電光掲示の文字で内容が分かる
7. 第3段階で、目の前の後頭部・顔の横の吊り革・顔の近くのスマホが「近いけれど不快すぎない」距離か
8. 頭を近づけると乗客が透ける
9. 急ブレーキで乗客だけが傾き、視点や部屋は揺れない
10. 謎の視線：斜め前の人がこちらを向き、戻る
11. 席を譲られる：空中に座っていた人が立って、何もない場所を示す
12. 終点で全員が消え、吊り革も広告も消え、「お疲れさまでした」のあと完全に静かになる
13. 「まもなく、始発駅です」で再び乗客が現れ、2周目が始まる
14. トリガー／ピンチで「おわる」が出て、選ぶとセッションが終わりタイトルに戻る
15. 72Hz を保てるか（重い場合は「ほどほど」で試す）

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` / `style.css` | タイトル画面（設定・注意書き） |
| `js/main.js` | XR／プレビューの切り替え、頭の位置を車内座標に直して director に渡す、「おわる」 |
| `js/director.js` | 進行（`CONFIG.T` の時刻表）、乗客の出し入れ、不条理イベント、アナウンス |
| `js/people.js` | 乗客の組み立て（骨組み→ポーズ→焼き込み）、こちらを向く・透ける・歩く・傾く |
| `js/car.js` | 吊り革と握り棒、中吊り広告、電光掲示、文字の板 |
| `js/audio.js` | 合成音のすべて |
| `js/voice.js` | アナウンスの読み上げ（speechSynthesis） |
| `js/geo.js` | 色つきの部品を1つのジオメトリにまとめる道具、種つき乱数 |
| `js/ui3d.js` | 「おわる」ボタンとコントローラーの光線（VR牢屋から流用） |
| `js/settings.js` | 混み具合・部屋の広さ・音の設定 |
